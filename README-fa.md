# مس‌آموز — اپلیکیشن اندروید

پوستهٔ بومی اندروید (Kotlin، بدون کتابخانهٔ جانبی) برای سامانهٔ مس‌آموز.

## رفتار برنامه
- سایت را از `SITE_URL` باز می‌کند. پس ورود با ایمیل و رمز عبور، همگام‌سازی پیشرفت و به‌روزرسانی محتوا مثل نسخهٔ وب کار می‌کند.
- کاربر برای دریافت محتوای جدید لازم نیست برنامه را دوباره نصب کند. کافی است `index.html` روی سرور عوض شود.
- پس از اولین اجرا، سرویس‌ورکر سایت آن را آفلاین هم نگه می‌دارد.
- اگر در اولین اجرا اینترنت نباشد، نسخهٔ داخل برنامه (`app/src/main/assets/www/index.html`) باز می‌شود. با برگشت اتصال، برنامه خودکار به سایت برمی‌گردد.
- فایل‌هایی که سامانه می‌سازد، مثل پشتیبان JSON و جدول CSV، در پوشهٔ **Downloads** گوشی ذخیره می‌شوند.
- دکمهٔ بازگشت گوشی:
  1. اول پنجره‌های باز را می‌بندد (انیمیشن، مودال‌ها، منوی کناری).
  2. بعد به صفحهٔ قبل برمی‌گردد.
  3. در صفحهٔ اول، با دو بار زدن از برنامه خارج می‌شود.
- پیوندهای بیرونی در مرورگر گوشی باز می‌شوند.
- در برنامه، دکمهٔ «نصب اپلیکیشن» سایت پنهان است.
- پیوندهای ایمیل (تأیید ایمیل و بازنشانی رمز روی `https://mesamoz.ir/`) با App Links داخل برنامه باز می‌شوند. شرطش این است که فایل `https://mesamoz.ir/.well-known/assetlinks.json` روی سرور باشد (در بستهٔ سرور هست) و APK با کلید ثابت mesamoz امضا شده باشد. اگر تأیید نشود، پیوند در مرورگر باز می‌شود و باز هم کار می‌کند.
- مشخصات: شناسهٔ نصب (applicationId) `ir.mesamoz.app`، حداقل اندروید ۷ (API 24)، هدف API 35. پکیج کد Kotlin (`namespace`) همان `ir.engpmis.academy` مانده است.

## تنظیم نشانی سایت
در `gradle.properties`:
```
SITE_URL=https://mesamoz.ir/
```

## ساخت APK

### روش ۱: Android Studio
1. پوشه را با Open باز کنید و صبر کنید Gradle همگام شود.
2. برای آزمایش: **Build ▸ Build App Bundle(s) / APK(s) ▸ Build APK(s)**.
3. برای انتشار: **Build ▸ Generate Signed App Bundle / APK ▸ APK**. یک keystore بسازید و آن را نگه دارید.

### روش ۲: GitHub Actions (بدون نصب چیزی)
1. پوشه را در یک مخزن GitHub روی شاخهٔ `main` قرار دهید (push کنید).
2. در تب **Actions**، کار «Build APK» اجرا می‌شود.
3. فایل `copper-academy.apk` را از بخش **Releases** مخزن دانلود کنید. این بخش عمومی است و ورود به GitHub لازم ندارد. همان فایل در Artifacts همان اجرا هم هست.
4. برای امضای ثابت، این چهار Secret را در **Settings ▸ Secrets and variables ▸ Actions** تعریف کنید:
   - `KEYSTORE_BASE64`: خروجی `base64 -w0 release.jks`
   - `KEYSTORE_PASSWORD`
   - `KEY_ALIAS`
   - `KEY_PASSWORD`

   بدون این Secretها، APK با کلید آزمایشی امضا می‌شود. این APK نصب می‌شود، ولی نسخهٔ بعدی روی آن به‌روزرسانی نمی‌شود و باید اول آن را حذف کرد.

کلید ثابت مس‌آموز (alias `mesamoz`) ساخته شده و چهار Secret آن ثبت شده است؛ کلید تازه نسازید. اگر روزی کلید عوض شود، اثر انگشت SHA-256 آن را در `assetlinks.json` سرور هم عوض کنید.

ساخت keystore (فقط اگر کلید نداشتید):
```
keytool -genkeypair -v -keystore release.jks -alias mesamoz -keyalg RSA -keysize 2048 -validity 10000
```

## انتشار برای کاربران
- APK را با نام `copper-academy.apk` در پوشهٔ `public/app/` سرور بگذارید.
- با این کار، در پنجرهٔ «نصب اپلیکیشن» سایت (زبانهٔ اندروید) دکمهٔ «دانلود اپلیکیشن اندروید (APK)» خودکار ظاهر می‌شود.
- در هر انتشار جدید، `versionCode` و `versionName` را در `app/build.gradle.kts` بالا ببرید.
- نسخهٔ آفلاین داخل برنامه را با کپی تازهٔ `Copper-Academy.html` در `app/src/main/assets/www/index.html` به‌روز کنید. این کار اختیاری است، چون محتوای اصلی از سایت می‌آید.

## iOS
اپ بومی iOS به مک، Xcode و حساب توسعه‌دهندهٔ اپل نیاز دارد. نسخهٔ PWA از Safari همان تجربه را روی آیفون و آیپد می‌دهد. راهنمای آن در پنجرهٔ «نصب اپلیکیشن» سایت آمده است.
